## DeskTodo 1.5.4

Fixes updates not showing up: DeskTodo could keep showing the previous version's interface from a
browser cache after you installed a new version (for example, the drag-to-rearrange feature from 1.5.3
not appearing). DeskTodo no longer keeps that cache, and clears the old one on first start.
Your tasks and notes are not affected.

- Right-click the top bar to see which version you're running (bottom of the menu).

Includes everything from 1.5.3: drag to rearrange tasks and note lines, and tidy long meeting links.

### Install
1. Close DeskTodo (if needed: **Task Manager** → **DeskTodo** → **End task**).
2. Download **DeskTodo-v1.5.4-windows.zip** below, extract it, and replace your **DeskTodo** folder.
3. Run **DeskTodo.exe** from the new folder. Your tasks and notes are kept.
