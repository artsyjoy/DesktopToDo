## DeskTodo 1.5.0

A desktop widget for your day: **At a glance**, **To-do** and **Notes** in one calm, rounded window.

### Install
1. Download **DeskTodo-v1.5.0-windows.zip** below.
2. Right-click the zip → **Properties** → tick **Unblock** → **OK** (avoids the "Windows protected your PC" warning).
3. Unzip it and keep the **DeskTodo** folder somewhere permanent (for example `C:\Users\<you>\Apps\DeskTodo`).
4. Run **DeskTodo.exe**. Your tasks and notes from earlier versions are kept.

Needs Windows 10 or 11 with the Microsoft Edge WebView2 Runtime (built into Windows 11 and most Windows 10 PCs).

### What's in it
- **At a glance:** big 24-hour clock, sunrise and sunset, your next meeting, today's task count,
  weather for two places (hourly forecast, humidity, wind, rain, UV) and a swipeable month calendar.
- **Outlook calendar** through its published ICS link (optional).
- **To-do:** today and the next six days; sub-tasks; unfinished tasks move to the next day at midnight.
- **Notes:** bold text and bullet lists, with Tab / Shift+Tab to nest bullets. Saved as you type.
- Light and dark themes with a smooth crossfade; GPU-smooth scrolling and transitions (WebView2).
- Borderless widget with Windows 11 rounded corners; resize the height from the handle on the bottom edge.
- Backups: right-click the top bar → **Export backup… / Import backup…**.
