## DeskTodo 1.5.1

Fixes a startup problem where DeskTodo could wrongly say the WebView2 Runtime was missing.

- **One DeskTodo at a time:** opening DeskTodo while it's already running now brings the open window
  to the front, instead of trying (and failing) to start a second copy.
- **Clearer startup errors:** the WebView2 message only appears when WebView2 is really missing.
  Any other problem says what went wrong, and details are saved to `%APPDATA%\DeskTodo\desktodo.log`.
- A broken saved window size is ignored instead of stopping the app from opening.

### Install
1. Close DeskTodo. If it won't close, open **Task Manager**, select **DeskTodo**, and click **End task**.
2. Download **DeskTodo-v1.5.1-windows.zip** below, right-click it → **Properties** → tick **Unblock** → **OK**.
3. Unzip it and replace your **DeskTodo** folder, then run **DeskTodo.exe**. Your tasks and notes are kept.
