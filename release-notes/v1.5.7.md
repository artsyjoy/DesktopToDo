## DeskTodo 1.5.7

### Fixed: freezing, and the pin
- DeskTodo could **freeze** (and need End task) when you toggled the pin, or now and then on its own. The
  background task that keeps the widget on your desktop used to wait for the window while adjusting it, and
  could get stuck waiting on the pin. Every window adjustment is now sent without waiting, so neither one can
  freeze the window.
- **Unpinning now really unpins.** In desktop mode the widget goes behind whichever app you switch to, and it
  no longer stays above other windows after you turn the pin off.
- The automatic Windows build now toggles the pin back and forth on a real window. It checks that the
  "on top" setting is right each time and that the app still responds.

### Install
1. Close DeskTodo (if needed: **Task Manager** → **DeskTodo** → **End task**).
2. Download **DeskTodo-v1.5.7-windows.zip** below, extract it, and replace your **DeskTodo** folder.
3. Run **DeskTodo.exe**. Your tasks and notes are kept. The right-click menu should say **DeskTodo 1.5.7**.
